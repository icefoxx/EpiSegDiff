# v0.2.1 — Integrated boundary-dynamics simulation (Task E)

**Objective.** After A–D, run the full discovery pipeline on planted
GAIN, LOSS, geometry, split/merge, and internal classes. Stratify by
normalization and scale. Do not include `BIDIRECTIONAL_SHIFT`.

**Hypothesis.** Intensity events (GAIN/LOSS) are recoverable after TMM
or background normalization. Geometry labels that are exact on interval
pairs (Task B) will be much noisier when domains are built from
condition-mean quantiles on NB counts.

**Methods.** `example_topology_event()` → `simulate_count_assay()` →
`run_simulated_discovery()` → `build_condition_domains()` (quantile,
not MACS) → `classify_boundary_events()`. Shared matcher:
`summarize_discovery_vs_truth()`.

**Simulation design.** 10 event classes × {narrow, broad} ×
{TMM, background, library_size} × 5 seeds = **300** genomes
(`n_bins = 400`). YAML `NULL` was parsed as empty and dropped; strict
NULL behavior is taken from Task D (not re-claimed here).

**Parameters.** Seed 20264. Config:
`config/validation/integrated_benchmark.yaml`.
Table: `benchmark/simulation/integrated_v021_results.tsv`.

**Results.**

FACT: Interval recall of the planted block is ≈ 1 for every class and
method. Precision (and therefore F1) is method-dependent.

FACT: Mean interval F1 (pooled scales):

| Truth | background | TMM | library_size |
|-------|-----------:|----:|-------------:|
| GAIN | 0.93 | 0.63 | 0.44 |
| LOSS | 0.46 | 0.60 | 0.50 |
| INTERNAL_GAIN | 0.93 | 0.87 | 0.54 |
| INTERNAL_LOSS | 0.90 | 0.82 | 0.72 |
| EXPANSION | 0.78 | 0.51 | 0.43 |
| CONTRACTION | 0.38 | 0.48 | 0.40 |
| LEFT_SHIFT | 0.59 | 0.49 | 0.33 |
| RIGHT_SHIFT | 0.48 | 0.44 | 0.34 |
| SPLIT | 0.41 | 0.47 | 0.40 |
| MERGE | 0.78 | 0.54 | 0.47 |

FACT: Under TMM, end-to-end **event-class** predictions from quantile
domains are poorly aligned with planted geometry (e.g. EXPANSION often
emitted as LOSS; COMPLEX rate 0.28). This is not the Task B ontology
failing; it is domain construction from noisy condition means.

FACT: Matched start/end MAE is 0 on planted GAIN/LOSS/INTERNAL blocks
(bin-aligned). SHIFT/SPLIT/CONTRACTION MAE is 0.4–6.4 kb.

FACT: `peak_caller = none` on every row.

INFERENCE: Use background or TMM, not library-size, if the goal is
interval precision. Do not treat pipeline topology labels as reliable
on NB-simulated geometry until domain construction is improved.

UNRESOLVED: A better peak-free domain constructor (local end_walk
around each candidate, Task C) was not wired into this 300-run loop.

**Uncertainty.** 5 seeds per cell. F1 differences of ~0.05 are noise;
library-size vs background on GAIN is not.

**Failures.** NULL class omitted because YAML `NULL` was dropped.
Documented, not silently removed after the fact.

**Interpretation.** Intensity recovery works. Geometry classification
through the current domain heuristic does not yet meet a methods-paper
bar.

**Limitations.** One chromosome, one effect size, five seeds.

**Decision: CONDITIONAL** for integrated geometry; intensity recovery
is acceptable under TMM/background.

**Next action.** For a real-data pilot, report Level I (GAIN/LOSS)
first. Treat Level II as experimental.
