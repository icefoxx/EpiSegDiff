# v0.4.2 — Genome-wide `filter=none`

## Objective

Complete the GSE280947 200 bp unfiltered continuous run that v0.4.1
left as `NOT_RUN`, without changing frozen statistical parameters.

## Methods

`analyze_continuous_matrix(..., filter_method="none", engine="pelt")`
with chromosome-wise `segment_genome`, per-chromosome checkpoints in
`results/v0.4.2/filter_none/checkpoints/`, workers=1.

Score remains `z = effect / max(|se|, 1e-6)` after
`log2(score + 0.01)` and limma. Penalty 24, `min_bins = 3`.

## Parameters

See `results/v0.4.2/filter_none/run_manifest.yaml`. Contrast
`JNKi - DMSO`.

## Uncertainty

INFERENCE: chrY is nearly constant unfiltered z-score, so PELT keeps
a large candidate set and becomes quadratic. Checkpoints still make
that cost restartable.

Median/p90 DER width of 600 bp means most called intervals sit on
the `min_bins` floor.

## Failures

None. Experimental FPOP was not used.

## Interpretation

Unfiltered whole-genome execution is now tractable under the frozen
model. The call set is **not** the 2/688 reference: removing the
signal mask yields thousands of additional DERs (see comparison
report). That is a filter effect, not a crash.

## Limitations

workers=1 for the official run (forking the 13.6M track was avoided).
IgG overlays were not required to declare completion.
