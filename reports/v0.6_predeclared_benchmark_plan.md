# v0.6 — Predeclared benchmark plan

Frozen before final interpretation. Later changes: `POST_HOC`.

## 1. Datasets

A = GSE280947 JUN (absolute 0.6, 200 bp, log2+0.01, PELT 24,
min_bins=3, JNKi−DMSO).

B = GSE110378 H3K27me3 (quantile 0.75, same otherwise, KO−Control).

## 2. Comparators

1. ESD Gaussian PELT (production).
2. Fixed IDR-union (A) / 3 kb quantile islands POST_HOC (B).
3. **Window-aggregate:** valid bins, per-bin limma FDR≤α, merge
   adjacent same-sign calls (csaw-like *region definition* on the
   **same** continuous model). Not BAM-csaw.
4. BAM-csaw / THOR: NOT_AVAILABLE unless binaries+BAMs exist.

## 3. Synthetic design

Toy chromosome, bin = 200 bp, n_bins = 1,000 (200 kb) unless a
wider event requires more.

**Primary grid (50 replicates/cell):**

- direction ∈ {GAIN, LOSS}
- width ∈ {200, 500, 1000, 2000, 5000, 10000, 25000, 50000} bp
- effect (linear planted Δ) ∈ {0.5, 1.5, 3.0} = weak/moderate/strong
- noise sd ∈ {0.05, 0.2, 0.5} = low/moderate/high
- boundary = sharp
- background = flat + 0.12 baseline

**Secondary (50 reps):**

- gradual: transition = 20% of event width on each side; truth =
  interval where planted Δ ≥ half the plateau
- spacing: gaps 0, 400, 2000, 10000 bp; same- and opposite-direction
  pairs; width 2000, effect 1.5, noise 0.2
- peak geometry: match / narrower / broader / cross-one /
  cross-multi / between / distal
- background: flat, heteroscedastic, locally elevated, long zeros

Seed = `20260 + cell_id * 1000 + rep`.

## 4. Matching rules

A call matches a truth event if reciprocal overlap ≥ 0.1 **or**
overlap ≥ 50% of the smaller interval (predeclared loose match for
detection). Boundary error uses the best-IoU call.

Merge: one call overlaps two truths.
Split: two calls overlap one truth.

## 5. Metrics

As taskbook §9. Primary α = 0.05.

**SECONDARY_MATCHED_CALL:** rank ESD and window-aggregate by
|effect| and cut to the same call count as the other method.

## 6. Null / calibration

- Global null: 100 independent 200 kb series, Δ=0, noise 0.2,
  baseline 0.12, full pipeline, α ∈ {0.01, 0.05, 0.10}.
- Label permutation: all valid balanced 2+2 partitions on Dataset A
  (only **2** exist besides true/reverse). Cannot reach 100 without
  invalid pseudo-replication.
- Selection bias: 50 synthetic moderate cells; (A) joint
  segment+test; (B) even samples define z-score for PELT, odd
  samples test. Classification per §11.4.

## 7. Class C

C1: 1 bp overlap with any **union peak** (not only DER) but not
RO≥50% with a conventional **DER**.
C2: overlaps a peak, extends ≥1 bin outside, not C1-only interior.
C3: overlaps ≥2 union peaks.
C4: no 1 bp overlap with any union peak.

Priority if multiple: C3 > C2 > C1 > C4 (a region is one class).

## 8. Promoter geometry

Fisher OR + 95% CI for promoter vs not:

- raw C vs A
- width-matched subsample of A to C
- distance-to-nearest-peak–matched
- shuffled intervals preserving chrom+width, n=5×C

## 9. Failure criteria

Material anti-conservatism = empirical FDP at α=0.05 **> 0.15**
on the global-null suite, or scrambled real-data DERs comparable
to 688 LOSS.
