# v0.4 Phase 3 — continuous statistical path

- Transform: `log2_pseudocount` / `log1p` / `none`.
- Filter: `none` (package default) / `absolute` / `quantile` /
  `control_based` / `auto` (deterministic 75th percentile of per-bin max).
- Replicated: limma (not edgeR, not DESeq2).
- Unreplicated: `inference_mode=descriptive`; FDR is NA; cannot claim
  significance without `allow_descriptive`.
- Schema: `standardize_primary_results()`.
