# v0.5 — Dataset selection

## Objective

Choose Dataset A (continuity) and Dataset B (independent validation)
**before** seeing EpiSegDiff results on B. Selection is not based on
favorable EpiSegDiff performance.

## Dataset A — GSE280947 (accepted)

| Field | Value |
| --- | --- |
| Accession | GSE280947 |
| Assay | CUT&RUN |
| Target | JUN (c-Jun) |
| Conditions | DMSO vs JNKi |
| Replicates | 2 vs 2 |
| Genome | mm10 (Ensembl-style seqnames) |
| BigWig | yes (spike-in + CPM) |
| BAM | **no** (not deposited; Layer 2 NOT_AVAILABLE) |
| Peaks | IDR DMSO n=4960; IDR JNKi n=1632 |
| Expected biology | JNK inhibition reduces JUN occupancy → LOSS of JUN signal |
| Orthogonal | IgG/Neg BigWigs; no matched RNA-seq in this package |

**Reason:** Frozen v0.4.x continuity profile. 2 GAIN / 688 LOSS at
absolute 0.6. Not re-selected here.

## Dataset B — GSE110378 (accepted)

| Field | Value |
| --- | --- |
| Accession | GSE110378 / PMID 30936419 |
| Assay | ChIPmentation |
| Target | **H3K27me3** (primary). H3K4me3 inspected and rejected (KO has 1 replicate). |
| Conditions | Vav-Cre wild-type Control vs Vav-Cre **Kdm6b-KO** HSCs |
| Replicates | H3K27me3 **2 vs 2** |
| Genome | **mm10** (Bowtie2; sample records) |
| BigWig | yes (GSM2989282/83 Control; GSM2989284/85 KO) |
| Peaks | hiddenDomains narrowPeak in series TAR |
| BAM | SRA only; not downloaded (Layer 2 NOT_AVAILABLE) |
| Expected biology | KDM6B/JMJD3 demethylates H3K27me3. KO is expected to **increase** H3K27me3 (GAIN of KO−Control) |
| Orthogonal | RNA-seq (3 vs 3) and ATAC-seq (3 vs 3) exist on GEO; used only if files are obtained |

**Reason accepted:** independent lab, tissue (HSC), assay
(ChIPmentation), and mark (H3K27me3) from GSE280947; ≥2 reps;
public BigWigs; known direction *a priori*; not chosen after
running EpiSegDiff.

## Candidates considered and rejected

| Accession | Why rejected |
| --- | --- |
| GSE126612 | Methods paper; digestion-time/antibody series, not a biological 2×2 perturbation of one mark |
| GSE44931 / GSE42355 | JQ1/BRD4 ChIP mostly unreplicated; WIG not a 2+2 BigWig design |
| GSE124661 | RNA-seq only (wrong series number collision with a CTCF search) |
| GSE280947 BAMs | Not deposited; cannot be Dataset B |
| H3K4me3 arm of GSE110378 | KO has a single replicate → inferential FDR forbidden |

## Decision

- A = GSE280947 JUN CUT&RUN (continuity)
- B = GSE110378 H3K27me3 Control vs Kdm6b-KO

No Dataset B result influenced this choice.
