# v0.4.1 — `summary_fun` contract

## Objective

Close the v0.4 API defect in which `summary_fun` accepted non-mean
values but still computed the mean. Gate A requires an honest
implementation or an explicit error.

## Methods

`summarize_rle_over_bins()` now implements:

- `mean`: `IRanges::viewMeans` (coverage-length weighted)
- `max`: `IRanges::viewMaxs`
- `area`: `IRanges::viewSums` = \(\sum_k x_k L_k\)

Unsupported values (`median`, `sum`, any other string) stop with
`summary_fun='…' is not implemented`. `read_bigwig_assay()` uses
`match.arg(c("mean","max","area"))` and therefore also rejects
unknown names before any import.

`median` was not implemented because a run-length-weighted median
is not provided by the current Views helpers and was not required.

## Parameters

Reference GSE280947 profile continues to use `summary_fun = mean`.
Sensitivity grids in this release also hold `mean`.

## Results

FACT: Hand-computable Rle tests pass:

- unequal runs `1×4 + 3×6` over `[1,10]`: mean `2.2`, max `3`, area `22`
- split bins `[1,5]`/`[6,10]`: means `1.4`/`3`, areas `7`/`15`
- uncovered bases encoded as 0: mean is length-weighted including zeros
- terminal short bin: area equals remaining bases
- non-finite Views summaries are replaced with 0
- `fun="median"` errors with `not implemented` (no silent mean)

FACT: `coarsen_bed_matrix()` averages **linear-scale** consecutive
bins; it is not a `summary_fun` and is not applied to log values.

## Uncertainty

INFERENCE: `viewMeans` / `viewSums` on a whole-chromosome Rle from
`rtracklayer::import(..., as="RleList")` treat uncovered bases as 0.
A sparse Rle shorter than the chromosome would drop those bases under
`na.rm=TRUE` before the finite-value cleanup. Production import uses
full-chromosome Rles.

## Failures

None in the unit suite (`tests/testthat/test-v041-summary-and-compare.R`).

## Interpretation

FACT: Gate A is PASS. Silent fallback to mean is gone.

## Limitations

- `median` and raw `sum` (unweighted run sum) are intentionally absent.
- `area` is signal × overlap length, not an unweighted sum of run values.

## Decision

**PASS** for the `summary_fun` contract.

## Next action

Keep GSE280947 on `mean`. Treat `max`/`area` as available but
unvalidated on this cohort (no grid was run for them).
