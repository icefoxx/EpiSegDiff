# v0.4.1 — Signal-filter sensitivity

## Objective

Run genome-wide `filter=none` at 200 bp and compare it quantitatively
with the GSE280947 profile `absolute 0.6`.

## Methods

`filter=none` marks every finite bin valid, so each chromosome is one
contiguous valid region (~1×10^6 bins on mm10 chr1 at 200 bp).
Segmentation uses the same replicated z-score as production
(`effect / max(|se|, 1e-6)`). `setTimeLimit` was applied (7200 s)
but **does not interrupt** `pelt_gaussian_cpp`.

An interrupt check every 1e5 PELT steps was added to
`src/fpop_core.cpp` after this run; it was not in the binary that
executed the killed job.

## Parameters

200 bp, `c = 0.01`, penalty 24, `min_bins = 3`.

## Results

| filter | n_valid | tested | GAIN | LOSS | status |
| --- | ---: | ---: | ---: | ---: | --- |
| none | 13,627,618 | NA | NA | NA | **NOT_RUN** |
| absolute 0.6 | 91,390 | 13,027 | 2 | 688 | PASS |

FACT: absolute 0.6 retains 91,390 / 13,627,618 bins (0.67%).

FACT: `filter=none` was killed after >30 minutes at ~100% CPU inside
Gaussian PELT on unfiltered genome-wide z-scores. RSS stayed low,
consistent with a tight C++ loop rather than an R memory stall.

INFERENCE: empty bins have near-zero residual variance, so
`z = effect / 1e-6` injects numerical noise across megabases of
background. PELT then sees a long noisy series (poor pruning).
This is the same phenomenon as the limma small-variance warning,
expressed at segmentation time.

## Uncertainty

Low-signal discoveries unique to `none` were **not** observed,
because `none` did not emit a primary table. They cannot be called
false positives or true positives from this release.

Replicate reproducibility of none-only calls was not tested.

## Failures

`filter=none` did not complete genome-wide. The cell is retained as
`NOT_RUN` with the reason above. It is not deleted.

## Interpretation

Absolute 0.6 is a **dataset-dependent** GSE280947 profile, not a
universal BigWig default. It is also what makes genome-wide PELT
tractable under the current z-score segmentation.

## Limitations

No additional control-aware filter was invented for this release.
`auto` remains a documented 75th-percentile rule and was not gridded.

## Decision

Gate D: **CONDITIONAL** (required genome-wide `none` comparison is
incomplete).
