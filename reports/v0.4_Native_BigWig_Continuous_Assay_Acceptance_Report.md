# v0.4 — Native BigWig continuous-assay acceptance

## 1. Executive summary

BigWig is a first-class **continuous** assay input. Count/NB/edgeR
is unchanged and is not used on BigWig values. GSE280947 reference
run: **2 GAIN / 688 LOSS** at FDR 0.05, contrast **JNKi − DMSO**,
emitted widths ≥ **600 bp**. Recommendation: **CONDITIONAL PASS**.

## 2. Implementation completed

- Assay contract `count+bam` vs `continuous+bigwig`
- `read_bigwig_assay()`, grid, QC, transform, filter, limma,
  segmentation, schema, CLI `scripts/run_episegdiff.R --config`
- Width enforcement `.enforce_min_bins()`
- Package version **0.4.0**

## 3. Deviations

- 50 bp / 100 bp / 500 bp genome-wide sensitivity not run (cost).
- `filter=none` not used as a genome-wide profile.
- Coarsen-to-500 not completed.
- `summary_fun` other than mean is accepted but still computes mean.

## 4. Input validation

FACT: Four JUN BigWigs import; seqnames Ensembl-style (`1`…`Y`).
Missing file / bad pairing fail with explicit errors (tests).

## 5. GSE280947 QC

FACT (same files as v0.3): DMSO JUN *r*=0.887, JNKi *r*=0.871 in
IDR bins; JUN/IgG = 2.92 (DMSO) vs 1.55 (JNKi). Genome-wide mean
signal is written in `sample_qc.tsv`. No hard correlation fail
threshold.

## 6. Statistical model and contrast

FACT: limma on `log2(score + 0.01)`. Contrast printed as
`JNKi - DMSO`. GAIN = effect > 0. edgeR is not called.

## 7. Segmentation results

FACT: 13,027 tested segments, 690 FDR≤0.05 (2 GAIN, 688 LOSS).
Median width 800 bp, minimum 600 bp.

INFERENCE: LOSS dominance matches JNK inhibition and IDR shrinkage.
Not a BAM-equivalent claim.

## 8. Width / min-width investigation

FACT: v0.3 400 bp = 2-bin segments from short CVRs / short last
PELT pieces. Fixed. Regression tests pass. See
`reports/v0.4_phase1_width_investigation.md`.

## 9. Sensitivity analysis

FACT: Only the reference cell is fully measured. Other grid cells
are logged as not run. Pseudocount was **not** chosen to maximize
calls.

UNRESOLVED: How GAIN/LOSS counts move at 100 bp or other
pseudocounts.

## 10. Regression tests

FACT: Unit/integration tests pass (`testthat::test_local`).
Synthetic BigWigs recover both directions. GSE280947 LOSS still
dominates GAIN.

## 11. Failures / warnings

- limma: many small variances offset from zero (expected on
  near-constant bins).
- QC hexbin “grid too coarse” warning on replicate scatter.

## 12. Known limitations

- No BAM/BigWig equivalence test.
- Software default filter is `none`; GSE280947 profile uses
  absolute 0.6 (dataset-specific).
- Unreplicated FDR is forbidden unless descriptive mode is requested.
