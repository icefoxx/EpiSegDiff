# v0.2.2 — Broad-domain failure analysis

**Objective.** Decide whether remaining broad-domain error is
implementation, candidate anchoring, normalization, or the local
method itself.

**Methods.** Oracle experiment on planted 10 kb and 20 kb GAIN blocks
(bin sizes 100 and 200 bp, 3 vs 3, depth 25). Candidates: exact truth
vs truncated (±3 bins). Size factors: true simulated vs TMM. Walkers:
legacy vs symmetric. Table:
`benchmark/simulation/broad_boundary_oracle_tests.tsv`.

**Parameters.** Seed 20269. Symmetric search radius 8; legacy 40 (its
v0.2.1-style wide window).

**Results.**

FACT: Median errors:

| candidate | norm | method | MAE_L | MAE_R | Hausdorff |
|-----------|------|--------|------:|------:|----------:|
| oracle_exact | true_sf or TMM | symmetric | 0 | 0 | 0 |
| truncated | true_sf or TMM | symmetric | 0 | 0 | 0 |
| either | either | legacy | 200 | 0 | 200 |

FACT: Switching from true size factors to TMM does **not** change
symmetric error (still 0).

FACT: Giving the method the exact true interval (oracle candidate)
does **not** leave multi-kb error for `symmetric`.

INFERENCE: The v0.2.1 multi-kb left error was **not** primarily
normalization and **not** “broad signal is unrecoverable.” It was the
legacy walker (wide `which.max` + edge mapping). After the fix, a
local walk with a candidate within a few bins recovers 10–20 kb
blocks in this NB design.

UNRESOLVED: Very low-gradient, highly heterogeneous broad marks on
real genomes. Stress cells with r ≪ width still fail; that is a
parameter choice.

**Failures.** None for the oracle+symmetric combination.

**Interpretation.** Broad Level II is no longer *blocked by a known
indexing bug*. It remains **experimental** on real data because
domain construction from condition-mean quantiles (v0.2.1 Task E)
was still unreliable. Boundary *refinement* is no longer the proven
bottleneck on these simulations.

**Limitations.** Only GAIN, one chromosome, moderate depth.

**Decision: CONDITIONAL** — refinement bottleneck lifted in
simulation; keep **broad Level II = EXPERIMENTAL** for the pilot
(do not start with H3K27me3).

**Next action.** Do not treat this as a reason to write NB-FPOP.
The loss was the walker, not the NB observation model.
