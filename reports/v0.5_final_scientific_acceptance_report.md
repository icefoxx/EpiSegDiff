# v0.5 — Final scientific acceptance

## Objective

Test whether adaptive differential segmentation adds reproducible
information beyond fixed peak-based analysis — not to maximize
EpiSegDiff calls.

## Methods

Predeclared plan (`reports/v0.5_predeclared_analysis_plan.md`).
Layer 1 holds BigWig+limma fixed and varies only region definition.
No BigWig→edgeR. IDR is not differential truth. Parameters were
not tuned to equalize call counts.

## Parameters

Dataset A: GSE280947 JUN, 200 bp, absolute 0.6 (frozen).
Dataset B: GSE110378 H3K27me3, quantile 0.75 (predeclared).

## Results — required questions

1. **Hypothesized advantage?** Recover reproducible differential
   *domains* that fixed peaks miss, fragment, or represent poorly
   (H1–H6).
2. **Predeclared?** Yes, before B results and before class counts
   were interpreted.
3. **Samples/contrasts matched?** Yes on A (same 4 BigWigs). B uses
   its own 4 H3K27me3 BigWigs.
4. **Comparator?** Layer-1 IDR-union peak-limma. Layer 2 BAM
   **NOT_AVAILABLE**.
5. **Primary calls?** ESD 2 GAIN / 688 LOSS; conventional 2 GAIN /
   1,688 LOSS.
6. **Shared differential bp?** 306,874 bp (Jaccard 0.198).
7. **Same vs opposite overlap?** 0 opposite-direction 1 bp overlaps.
   Shared class A = 329.
8. **Effect concordance?** Pearson 0.864; sign 0.984; called-sign 1.0.
9. **Replicate support?** Class A and C have similar |effect| and
   FDR; scrambled labels yield 0 DERs.
10. **Signal-strength among classes?** B slightly weaker than A/C.
11. **Fragmentation / broader domains?** ESD median 800 vs 620 bp;
    frag_index 0.575. PELT LOSS 688 vs bin-FDR LOSS 240.
12. **Synthetic boundary accuracy?** precision=recall=1, L1=0 on
    all seven planted cases.
13. **Boundary-shift recovery?** `cross_peak_boundary` detected as
    one DER, L1=0.
14. **Motif support for ESD-specific TF regions?**
    Class C 32.4% vs background 25.0% (OR 1.44, p=0.0048). Shared
    A is much higher (66.6%). Support vs background, not vs peaks.
15. **Annotation differences?** Class C promoter-heavy (65% vs 28%
    in A).
16. **Pathways?** No BH-significant GO (q≈0.96).
17. **Orthogonal evidence?** Not formally scored (IgG unused;
    B RNA/ATAC not imported).
18. **Null?** True 688 LOSS → 0/0 on both scrambled 2+2 partitions.
19. **Fixed-bin ablation?** 2/240 vs PELT 2/688.
20. **Fixed-peak ablation?** 2/1,688 (more sensitive, same
    direction).
21. **Robustness?** v0.4.1 12-cell grid: LOSS dominates every cell.
22. **`filter=none`?** v0.4.2: 4,866/4,608, mostly low-signal;
    **does** change global dominance. Kept secondary.
23. **Dataset B?** ESD 4,411 GAIN / 2,165 LOSS and POST HOC islands
    886 / 360 — both GAIN-dominant as expected. Jaccard 0.30.
24. **What would falsify?** Opposite-direction overlap with peaks;
    null partitions reproducing 688 LOSS; Dataset B reversing the
    expected GAIN; synthetic missing one planted direction.
25. **Alternative explanations?** Class C promoter hits may be
    short TSS-proximal changes already near IDR peaks (RO<50%).
    Peak-limma’s extra 1,361 calls may be real JUN losses ESD
    over-smooths.
26. **Decision?** **CONDITIONAL PASS**.
27. **Justified claim?** On GSE280947 JUN, adaptive PELT and
    peak-limma agree on **direction** and on **329 shared DERs**;
    PELT is **not** a bin-wise FDR in disguise; **361** ESD-only
    intervals exist and are promoter-enriched; label permutation
    kills the 688 LOSS. On GSE110378, PELT recovers the expected
    **H3K27me3 GAIN**.
28. **Unjustified claims?** That ESD is generally better than
    peaks; that class C is true JUN binding; that 200 bp/0.6/0.01
    are universal; BigWig=BAM; more calls=better; motif support;
    pathway support; Dataset B peak-class structure.
29. **Next version?** A v0.5.1 motif/orthogonal close, or a
    scientific v0.6 with BAMs and a deposited peak set on Dataset B.
    Not NB-FPOP by default.

## Uncertainty

INFERENCE: the scientific contribution on A is **representational
(domains vs bins)** plus **partially peak-independent intervals**,
not a replacement for peak-limma sensitivity.

## Failures

- Dataset B conventional is POST HOC islands (no deposited peaks)
- Layer 2 BAM NOT_AVAILABLE

## Interpretation

A fair benchmark was run. The result is **not** “ESD wins.” It is
that adaptive segmentation is a distinct, direction-correct,
null-collapsing region definition with a non-empty peak-independent
set whose extra biological support is **not proven**.

## Limitations

n=4 samples; no BAM layer; H3K27me3 quantile filter yields a huge
tested space on B.
