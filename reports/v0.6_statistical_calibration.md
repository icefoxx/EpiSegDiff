# v0.6 — Statistical calibration

## Objective

Test false-positive behavior of the **complete** pipeline
(segment then test) and selection dependence.

## Methods

- Global null: 100 series, 200 kb, Δ=0, sd=0.2, filter=none,
  α=0.05 (plus 50 series at α=0.01/0.05/0.10).
- Real permutation: 2 balanced 2+2 label swaps on GSE280947
  (all that exist besides true/reverse).
- Split diagnostic: 50 moderate planted series; joint vs PELT on
  a 1-vs-1 descriptive pair.

## Parameters

Same synthetic engine as §8. Production real-data filter is 0.6,
not none.

## Results

FACT, synthetic global null (α=0.05):

| method | mean n_DER | P(any DER) |
| --- | ---: | ---: |
| ESD | 0.99 | **0.36** |
| window | 0.00 | 0.00 |

ESD null n_DER 50/90/100% = 0 / 3.1 / 11.

Nominal vs P(any DER): α=0.01 → 0.30; 0.05 → 0.36; 0.10 → 0.48.

FACT, GSE280947 permutations: 2/688 → **0/0** and **0/0**.

FACT, split: joint always detected the planted event (50/50);
split descriptive PELT emitted ~177 raw segments (not FDR calls).
The split diagnostic does **not** compare like-with-like DERs.

## Uncertainty

INFERENCE: under **filter=none** toys, ESD is **mildly
anti-conservative** (36% of null 200 kb series have ≥1 FDR≤0.05
call). Window aggregation is conservative.

INFERENCE: the **production filtered** GSE280947 profile is
**conservative** under the only valid label permutations.

Predeclared “material” bar was empirical FDP>0.15. On null series,
all calls are false; P(any call)=0.36 exceeds 0.15, but mean burden
is ~1 call / 200 kb at filter=none — not the 688-LOSS real profile.

Classification: **mildly anti-conservative** (unfiltered
synthetic) / **conservative** (filtered real permutation).
Overall: **unresolved as a single label**.

## Failures

Cannot run ≥100 real permutations with n=4. Split test did not
implement a full two-replicate inferential split.

## Interpretation

Gates E/F: **CONDITIONAL**. Do not claim calibrated region-level
FDR for filter=none. Do not hide synthetic inflation.

## Decision

No silent production change. Sample-splitting remains exploratory.
