# v0.5 — Negative controls

## Objective

Ask whether the 2/688 JUN LOSS signal collapses when condition
labels are scrambled.

## Methods

All balanced 2+2 partitions of the four samples except the true
assignment and its exact reverse (2 remaining partitions). Same
ESD config as primary.

## Parameters

absolute 0.6, 200 bp, PELT 24, min_bins 3.

## Results

FACT:

| partition | GAIN | LOSS |
| --- | ---: | ---: |
| 0 (true JNKi vs DMSO) | 2 | 688 |
| 1 (scrambled) | 0 | 0 |
| 2 (scrambled) | 0 | 0 |

## Uncertainty

Only two balanced nulls exist with n=4. That is a design limit, not
a hidden choice.

## Failures

None.

## Interpretation

Gate F: **PASS**. The primary LOSS call set is assignment-specific.

## Decision

PASS.

## Next action

Do not overinterpret two nulls as a full permutation distribution.
