## Narrow-domain numbers (symmetric walker)

FACT (method comparison, 50-bp bins, mild noise):

```text
median |E_L| = 0
median |E_R| = 0
p90 Hausdorff = 0
signed L = 0
signed R = 0
```

FACT (legacy, same design): median |E_L| = 50 bp (one bin), signed L = −50.

INFERENCE: Remaining narrow error after the fix is at or below one bin
when the candidate is within ~2 bins. That is acceptable relative to
50–100 bp bins and typical TF/H3K27ac feature widths.

## Broad-domain

FACT: Oracle + symmetric recovers 10–20 kb planted GAIN with MAE 0
when the candidate is exact or truncated by 3 bins.

INFERENCE: v0.2.1’s 7.8 kb left error was the legacy walker.

**broad Level II = EXPERIMENTAL / not the first pilot.** Do not start
with H3K27me3/H3K9me3.

## Answers to the seven primary questions

1. **Cause of left/right asymmetry?** Implementation: edge-to-coordinate
   mapping (`L = start[k]` vs `start[k+1]`), `which.max` first-tie on a
   window that contains both jumps, and index swapping.
2. **Is `end_walk` intrinsically directional?** The *legacy* code was.
   The *symmetric* algorithm is a mirror pair (documented).
3. **Does reversing the signal reverse the error?** Yes after the fix
   (both zero). No for legacy.
4. **Bin size / radius / padding / effect / width?** Narrow cells are
   robust for r ≥ 5. Broad cells fail when r ≪ width (search support).
5. **Can narrow accuracy improve without changing the statistical
   model?** Yes — walker only.
6. **Broad failure?** After the oracle test: not normalization, not
   “always unrecoverable.” Legacy implementation + too-small radius.
   Real broad marks still experimental.
7. **Level I ready for a scoped CUT&RUN/ChIP pilot?** **Yes.**

## Decision: PASS

Proceed to **exactly one** initial cohort:

```text
paired-end CUT&RUN or ChIP-seq
≥2 biological replicates / condition
narrow/local mark (TF, H3K27ac, or H3K4me3)
TMM = primary; background = sensitivity
Level I GAIN/LOSS = primary output
Level II = experimental
```

Do **not** start with H3K27me3/H3K9me3. Do **not** open full
competitor benchmarking in the same breath as this first cohort. Do
**not** implement NB-FPOP: the measured v0.2.1 boundary failure was
the walker, not the NB cost.

**Failures.** None that block the narrow Level I pilot.

**Limitations.** No real BAM was run (prohibited here). Genome-wide
calibration is still the v0.2.1 short-chromosome result.

**Next action.** Point `config/example.yaml` at one real narrow
paired-end cohort and run Level I with TMM. Log everything. Stop
after that pilot’s QC before expanding marks or competitors.
