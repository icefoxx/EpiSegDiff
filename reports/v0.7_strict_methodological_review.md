# v0.7 — Strict methodological review

**Reviewed artifact:** `reports/v0.7_final_methodological_acceptance_report.md`  
**Evidence tables:** `results/v0.7/*.tsv`  
**Review type:** Adversarial / method-development gate  
**v0.8 implementation:** **not authorized** until R1–R5 close.

## Objective

State what v0.7 actually established, separate parameter-level
from formulation-level failures, and lock the evidence required
before any architecture freeze.

## Verdict

**CONDITIONAL PASS — method-development milestone only.**

v0.7 did **not** establish a universal narrow-to-broad method,
a validated automatic multi-scale engine, calibrated
region-level FDR, or superiority over csaw/THOR.

The strongest defensible conclusion:

> v0.7 modularized EpiSegDiff and showed that narrow-event
> recovery is possible under alternative score/segmentation
> configurations while strong broad-event performance is
> retained by raw-effect + PELT. It did not produce a
> validated scale-adaptive decision rule, failed nested
> multi-scale recovery, retained same-direction merging and
> gradual-boundary limitations, and did not establish
> region-level FDR control.

## What v0.7 proved

### FACT 2.1 — Narrow failure is not structurally unavoidable

From `score_engine_benchmark.tsv` and
`segmentation_engine_benchmark.tsv` (nrep=50, zeros included):

```text
standardized + PELT min1:  200 bp F1 = 0.47;  500 bp F1 = 0.64
raw_effect + fused:        200 bp F1 = 0.62
raw_effect + PELT:         200/500 bp F1 = 0
```

**Supported:** narrow recovery is achievable inside the modular
framework.  
**Not supported:** narrow events are robustly solved.

### FACT 2.2 — Raw-effect PELT is the strongest demonstrated broad configuration

```text
raw_effect + PELT: F1 = 1 at 2–50 kb; one call; 0 bp error
```

This is the current **broad baseline**, not universal biological
superiority. Gradual ramps degrade (F1 0.89, ~1 kb error). Real
truth boundaries are unknown. csaw/THOR are absent.

### FACT 2.3 — Fused lasso is useful but not universal

```text
200 bp F1 = 0.62
500 bp raw-effect F1 = 0.06
50 kb F1 = 0.64 vs PELT 1
H3K27me3 chr19 fused = 4 GAIN / 12 LOSS
```

Useful narrow-scale information. Cannot replace PELT globally.

### FACT 2.4 — Current WBS implementation failed its intended role

WBS F1 = 0 at 200–2000 bp. Merge rate 0 is non-informative
when the engine does not call. WBS **as a class** is not
falsified; this implementation/penalty is.

### FACT 2.5 — Automatic routing failed held-out validation

`heldout_routing.tsv`: all 2 kb events routed `narrow`;
held-out 2 kb F1 = 0.52 vs PELT 1.00; 500 bp test F1 = 0.

### FACT 2.6 — Nested multi-scale recovery failed

`nested_event_metrics.tsv`: PELT, WBS, fused, and union all
have mean `n_merged = 1`. This is a **major blocker**, not a
cosmetic cell.

### FACT 2.7 — Candidate union is not multi-scale inference

Union matches the better isolated caller and does not solve
the 500 bp gap or nested identity.

## Central methodological concern

INFERENCE (not a theorem): a locus is explained by **one**
segmentation of **one** derived differential signal. Nested
truth

```text
D(x) = B(x) + L(x) + ε(x)
```

may require an additive/hierarchical representation. This must
be tested against the alternative that better
parameterization/resolution is sufficient (R1–R5).

## Parameter-level vs formulation-level

**Likely parameter/implementation-sensitive**

- WBS narrow failure (penalty, sampling, threshold).
- Fused 500 bp instability (λ, noise, scaling). Broad
  real-data sign incoherence still argues against global fused.
- PELT narrow floor (`200 bp × min_bins=3`). Alternative
  score/min-length already improves recovery.

**Likely formulation-level**

- Nested narrow-on-broad: several families + union fail the
  same test.
- Automatic one-scale routing cannot represent a locus that
  contains both scales.
- Same-direction merging (PELT gap-10 merge 0.90 vs fused
  0.12): single global penalty vs fragmentation.
- Gradual boundaries: point-change model vs transition-zone
  truth.

## Strict statistical review

FACT: factorial detection used a **frozen MAD threshold**.
`infer_regions` used limma/descriptive rules. They are not
interchangeable.

FACT: MAD-threshold `P(any false)=0` on four synthetic nulls
supports only that detection rule.

FACT: same-data `P(any false)=0.06`; pooled 0.08; split 0;
cross-fit 0. v0.6 unfiltered inflation (0.36 / 200 kb) is
reduced. This is **not** region-level FDR.

UNSUPPORTED: calibrated FDR; pooled-boundary improvement
(0.08 is worse); production-ready splitting (WBS recall
0.12 → 0.02).

## Two-mode proposal

```text
broad default:   raw + PELT min3
narrow overlay:  standardized + PELT min1  or  fused
```

This is a **v0.8 control**, not a final architecture. A user
cannot know the unknown event scale. Nested truth cannot be
represented by choosing one mode.

## Manuscript readiness

**Ready:** modular benchmarking; geometry-dependent regime
map; failure of naive routing; detection vs FDR distinction.

**Not ready:** universally scale-adaptive; beats csaw/THOR;
calibrated region-level FDR; one model solves narrow and
broad; nested/hierarchical structure resolved.
