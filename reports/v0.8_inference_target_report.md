# v0.8 — Inference target declaration

## Objective

Separate discovery from testing and name the provisional
inferential target before architecture acceptance.

## Methods

Path B discovery emits scale-typed regions. Downstream testing
may use limma on region means (same-data) or descriptive
`|effect|` support. MAD-threshold discovery is used in the
synthetic falsification suite (same rule as v0.7 factorial).

## Declared target (provisional)

```text
Primary reporting target:
  family-wise P(any false region) under the stated discovery rule
  + component leakage rates (false local | broad-only;
    false broad | local-only)

Not claimed:
  region-level FDR
  hierarchical FDR
  component-level FDR
```

## FACT / INFERENCE / UNRESOLVED

FACT: v0.7 showed MAD-threshold nulls can be conservative while
same-data limma still has mild P(any)>0.

INFERENCE: until Gate H passes with an explicit multiplicity
family, support statistics (`|effect|`, optional limma FDR on
fixed regions) are descriptive.

UNRESOLVED: selective inference for data-dependent Path B
regions; calibrated hierarchical FDR.

## Decision

Do not print "FDR" on Path B outputs unless the family is named
and empirically checked in `null_calibration.tsv`.

## Next action

Use null/leakage tables to accept or reject candidates.
