# v0.4.2 — `filter=none` versus absolute 0.6

## Objective

Quantify how the unfiltered call set relates to the frozen GSE280947
reference (2 GAIN / 688 LOSS) and characterize none-only intervals.

## Methods

`compare_continuous_runs` on all tested segments plus DER bp
set-difference. Linear signal for none-only / strata is the per-bin
max of the four JUN BigWig scores (100 bp cache coarsened to 200 bp).
Strong DERs: called and `|effect| >= 1` (predeclared).

## Parameters

Same 200 bp / 0.01 / penalty 24 / `min_bins = 3` / `JNKi - DMSO`.
Reference table: `results/v0.4.1/reference_primary.tsv`.
None table: `results/v0.4.2/filter_none/primary.tsv`.

FACT: significant none calls concentrate in the **lowest** positive
signal quartile, not in Q4. Q4 still shows LOSS dominance
(391 LOSS / 17 GAIN), in the same direction as the 0.6 reference.

FACT: 97.3% of none-only intervals have max linear signal < 0.6, so
they are largely the bins the absolute filter removes. They are
**not** labeled false positives here.

INFERENCE: the global GAIN≈LOSS balance under `none` is produced by
low-signal segments. High-signal segments remain LOSS-dominated.

Replicate consistency: every called DER has a replicated limma FDR
(2 vs 2). Q1 median FDR is 0.059 with thousands of FDR≤0.05 calls,
so the model treats many low-signal intervals as repeatable. That is
not the same as biological JUN occupancy.

## Uncertainty

All-tested effect Pearson is low (0.20) because `none` fragments the
genome into many short CVR-scale segments that only partially overlap
the 0.6 segments. Called-region signs still agree where they overlap.

IgG/Neg BigWigs were not scored in this table.

## Failures

None in the comparison computation.

## Interpretation

Removing the 0.6 mask **does** change the headline GAIN/LOSS story
if one counts every FDR≤0.05 interval. It does **not** reverse the
high-signal LOSS direction. Absolute 0.6 remains a
dataset-dependent profile, not a universal truth set.

## Limitations

Strata use per-interval max of JUN linear signal, not IgG-subtracted
enrichment. No new threshold is proposed.

## Decision

Gate E: **PASS**.

## Next action

Keep 0.6 as the GSE280947 profile default. Document `none` as a
supported, more liberal scan.
