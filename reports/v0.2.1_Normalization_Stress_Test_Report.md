# v0.2.1 — Normalization stress test (Task A)

**Objective.** Quantify composition-induced background \(\hat\beta\) bias
and false flanks under `library_size`, `TMM`, DESeq2-style
median-of-ratios, and a lower-quantile **background** reference.

**Hypothesis.** Library-size offsets convert a true
`STABLE | GAIN | STABLE` pattern into `weak LOSS | GAIN | weak LOSS`
once a large one-sided gain changes composition. TMM/DESeq2 should
resist moderate shifts; a background-bin reference should resist
*one-sided* global gains but can fail when GAIN and LOSS are balanced
(low-count LOSS bins contaminate the reference).

**Methods.** `compose_fraction_events()` plants GAIN/LOSS blocks.
Size factors are estimated from counts only (no arbitrary factors).
Per-bin edgeR QL \(\hat\beta\) and \(Z\) are computed. Discovery
(PELT + QL + BH) is run on a subset of cells (`frac` in
{0, 0.05, 0.25, 0.50} × gain-prop 0.5 or 1.0).

**Simulation design (reduced; full Cartesian documented as too large).**

- `n_bins = 600`, primary: 3 vs 3, depth 20, \(\phi=0.10\),
  effect 1.5, block width 20 bins, 4 replicates per cell
- Fractions: 0, 1, 5, 10, 25, 50%
- GAIN:LOSS: 50:50, 70:30, 90:10, 100:0
- Satellites at 10% / 50:50: n_rep ∈ {2,5}, depth ∈ {8,50},
  \(\phi=0.40\), effect 2.5, widths 8 and 40
- Methods: `library_size`, `TMM`, `deseq2`, `background` (row-mean
  ≤ 50th percentile, then median-of-ratios)

**Parameters.** Seed 20261. Config:
`config/validation/normalization_stress.yaml`.
Table: `benchmark/simulation/normalization_stress_results.tsv` (432 rows,
2 failed cells recorded).

**Results.**

FACT: At 0% differential, all four methods have median background
\(\hat\beta\) bias \(\approx 0\) (\(|\mathrm{bias}| < 0.01\)).

FACT: One-sided GAIN (`gain_prop = 1`), median signed background bias:

| frac | library_size | TMM | deseq2 | background |
|------|-------------:|----:|-------:|-----------:|
| 1% | −0.027 | −0.010 | −0.014 | −0.018 |
| 5% | −0.160 | −0.044 | −0.039 | +0.014 |
| 10% | −0.302 | −0.080 | −0.098 | +0.001 |
| 25% | −0.604 | −0.250 | −0.298 | +0.002 |
| 50% | −1.004 | −0.826 | −0.795 | −0.002 |

FACT: At 25% one-sided GAIN, library-size median false-region count is 9
vs 0.5 for `background` and 4 for TMM. Recall stays ≈ 1 for all methods
that call the planted GAIN.

FACT: Balanced 50:50 at 50% differential: TMM bias −0.022 (good);
`background` bias +0.61 (fails). Library-size −0.51.

INFERENCE: Do **not** choose a method by power. Library-size has high
recall and high false flanks. Background is the only method that kept
one-sided 25–50% genomes centered; TMM is the only method that stayed
centered under balanced large shifts.

**Validity envelope (filled after the grid).** PASS = median
\(|\mathrm{bias}_{\mathrm{background}}| < 0.10\) on that cell.

| Method | 0–5% any mix | 10% one-sided | 25–50% one-sided | 25–50% 50:50 |
|--------|--------------|---------------|------------------|--------------|
| library_size | FAIL from 5% one-sided | FAIL | FAIL | FAIL |
| TMM | PASS | PASS (0.08) | FAIL | PASS |
| deseq2 | PASS | borderline (0.10) | FAIL | PASS |
| background | PASS | PASS | PASS | FAIL |

**Uncertainty.** 4 Monte Carlo replicates per primary cell. Medians are
stable in sign; magnitudes at 1% are within noise of 0.

**Failures.** 2 cells wrote errors (kept in the TSV). Spike-in was
implemented as *dedicated reference bins* only; it was not part of this
grid (would require a separate coherent spike-in genome).

**Interpretation.** Library-size is not an acceptable default. TMM is
the better default when the differential fraction and GAIN:LOSS mix are
unknown. Use `background` when a large one-sided composition shift is
expected and the lower half of the genome is still mostly non-differential.

**Limitations.** 600-bin chromosomes. No real library-prep spike-in.
Discovery subset is not the full Cartesian product.

**Decision: PASS (Gate A)**

Background bias is quantified; failure regimes are identified; at least
one strategy (TMM in the intended moderate-fraction regime;
`background` for large one-sided shifts) is acceptable.

**Next action.** Set package default to TMM (already). Document
`background` for one-sided global shifts. Do not use library-size
except as a negative control.
