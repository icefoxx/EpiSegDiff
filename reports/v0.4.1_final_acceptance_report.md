# v0.4.1 — Final acceptance report

## Objective

Close remaining v0.4 PARTIAL / UNRESOLVED items and decide
**PASS / CONDITIONAL PASS / FAIL** for native BigWig continuous-assay
support.

## Methods

Executed `EpiSegDiff_v0.4.1_BigWig_Validation_Closure_Taskbook.md`
phases 1–11. Parameter sensitivity is a robustness analysis, not
selection against a truth set. Deposited IDR peaks were not used as
differential ground truth. BAMs were not analyzed.

## Parameters

Frozen in `config/validation/v0.4.1_gse280947_reference.yaml`:

- assay: continuous / BigWig / mm10
- bin 200 bp, `summary_fun = mean`
- `log2(score + 0.01)`
- filter `absolute 0.6`
- limma, Gaussian PELT, `min_bins = 3`, FDR 0.05
- contrast `JNKi - DMSO`

Cache: `cache/gse280947_100bp_signal_matrix.rds` (27,255,223 bins,
built in 99 s, invalidated on checksum/genome/summary change).

## Results — required questions

1. **Does `summary_fun` now have an honest implementation contract?**
   Yes. `mean` / `max` / `area` are implemented; other values error.
   Silent mean fallback is gone. Gate A **PASS**.

2. **Do 100, 200, and 500 bp runs all complete genome-wide?**
   Yes. 500 bp is genuine integer coarsening of the linear 100 bp
   cache. Gate B **PASS**.

3. **How strongly do effect estimates agree across bin sizes?**
   Pearson on all overlapping tested segments: **0.858** (100 vs 200)
   and **0.863** (500 vs 200). Sign concordance **0.973** / **0.988**.

4. **How stable are strong DERs across bin sizes?**
   Strong-reference recovery: **0.101** (100 bp), **0.184** (500 bp).
   Strong-region sign concordance is **1.0**. Called sets move more
   than effect signs.

5. **How much instability is explained by changing minimum physical
   segment width?**
   Floors are 300 / 600 / 1500 bp and match observed minima. Median
   widths sit on those floors at 100 and 500 bp. Low DER Jaccard
   (0.046 / 0.156) is therefore partly a definition change, not only
   a biological disagreement.

6. **How sensitive are effects and calls to pseudocount 0.001–0.1?**
   At 200 bp, effect Pearson vs 0.01 is **0.995–0.999**. LOSS calls
   increase with `c` (668 → 688 → 787 → 854). GAIN stays 2.

7. **Is pseudocount sensitivity concentrated in low-signal regions?**
   No. Q1 sign-flip rates (0.006–0.021) are **lower** than Q4
   (0.016–0.057). Q1 is dominated by exact-zero bins whose effect is
   0 for every `c`.

8. **What changes under `filter=none`?**
   Unknown at the call level. The cell is **NOT_RUN** (PELT on 13.6M
   unfiltered z-scores killed after >30 min at 100% CPU). Absolute
   0.6 retains 0.67% of bins (91,390 / 13,627,618).

9. **Are low-signal `filter=none` discoveries reproducible across
   replicates?**
   UNRESOLVED — no `none` primary table.

10. **Does the full 12-cell bin-size × pseudocount grid complete?**
    Yes. **12 / 12 PASS**.

11. **Do any configurations reverse the dominant GSE280947 LOSS
    conclusion?**
    No. Every completed cell has LOSS ≫ GAIN (139–854 vs 1–2).

12. **Does any reasonable configuration produce widespread sign
    reversal?**
    No. Sign concordance ≥ 0.972; strong-region sign concordance = 1.

13. **What is the strong-reference-region recovery range?**
    **0.101 – 1.000** (low end = 100 bp; high end = 200 bp
    pseudocount neighbors).

14. **What is the DER bp-Jaccard range relative to reference?**
    **0.046 – 0.970** (low end = 100 bp; high end = 200 bp / 0.001).

15. **What do the limma small-variance warnings affect?**
    1,328,741 bins (9.75%), median linear signal 0. Offset-from-zero
    warnings match that count.

16. **Are those warnings harmless, potentially influential, or
    materially influential?**
    **harmless / expected**. Default vs robust+trend effects correlate
    at 1.00 with median absolute difference 0.

17. **Are all v0.4 critical regression tests still passing?**
    Yes (22 + 7 + 28 in the three targeted files). See
    `reports/v0.4.1_regression_report.md`.

18. **Is BigWig fully separated from edgeR/count inference?**
    Yes. Continuous path uses limma only. Assay contract rejects
    mixed families.

19. **Is v0.4.1 PASS, CONDITIONAL PASS, or FAIL?**
    **CONDITIONAL PASS**.

20. **Which parameters are justified as defaults and under what
    assumptions?**
    - `summary_fun = mean`: **stable default candidate**
    - `bin_size = 200`: **dataset-dependent** (GSE280947 profile)
    - `pseudocount = 0.01`: **dataset-dependent**
    - `filter = absolute 0.6`: **dataset-dependent** (also required
      for tractable genome-wide PELT under the current z-score)

21. **What remains necessary before BAM-versus-BigWig concordance
    testing?**
    Primary JUN BAMs for the same samples; a count/NB path on those
    BAMs; a predeclared concordance metric. Deposited BigWigs must
    not be treated as fragment counts.

22. **Is the project ready for the next scientific-development
    version?**
    Ready for **review** of this closure. Not automatically ready to
    start v0.5 / NB-FPOP / competitor work from this report.

## Uncertainty

INFERENCE: Jaccard < 1 across bin sizes is expected when minimum
width and segmentation granularity change. It is not proof that one
setting is wrong.

FACT: reference GAIN/LOSS is identical to v0.4, so later sensitivity
is interpretable.

## Failures

- `filter=none` genome-wide PELT did not finish. Cell retained with
  reason. This alone blocks full PASS (taskbook §10 / Gate D).

## Interpretation

Native BigWig / continuous-assay support remains scientifically
valid under the documented model. The 12-cell grid does not reverse
LOSS dominance or effect signs. The remaining block is an incomplete
unfiltered segmentation profile, not a silent API lie, a direction
error, or an edgeR leak.

**PASS** is not claimed. PASS would still **not** mean BigWig ≡ BAM
or that 200 bp / 0.01 is universally optimal.

## Limitations

- No BAM/BigWig equivalence
- No competitor benchmarking
- No NB-FPOP
- No publication claim
- `max` / `area` implemented but not gridded on GSE280947
