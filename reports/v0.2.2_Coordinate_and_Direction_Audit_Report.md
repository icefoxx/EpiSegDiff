# v0.2.2 — Coordinate and direction audit

**Objective.** Fix the YAML no-change label, prove `[start,end)` is
used consistently, and determine whether v0.2.1 left/right asymmetry
was an implementation bias.

**Methods.** Toy chromosome (1000 bp, 100-bp bins, region `[300,700)`).
Noiseless step functions. Reverse-signal invariance on 40 random
blocks × `{legacy, symmetric}`.

**Parameters.** Seed 20266. Tables:
`benchmark/simulation/boundary_coordinate_tests.tsv`,
`benchmark/simulation/boundary_reverse_invariance.tsv`.

**Results.**

FACT: The simulation label is `NO_CHANGE`. It survives R `yaml`
write/read, TSV export/import, and Python `yaml.safe_load` of
`config/validation/integrated_benchmark.yaml` (the unquoted `NULL`
key is gone). Five `NO_CHANGE` genomes were simulated and retained
the label. Deprecated alias `"NULL"` still maps to `NO_CHANGE`.

FACT: The 1000-bp toy reconstructs **exactly** `start=300`, `end=700`
from bins, CVRs, Gaussian OP segments, and BED export. No ±1
tolerance was used.

FACT: On noiseless steps, **legacy** `end_walk` is directional:

| version | median \|E_L\| | median \|E_R\| | median signed L | median signed R | mean invariance Δ |
|---------|---------------:|---------------:|----------------:|----------------:|------------------:|
| legacy | 50 | 100 | −50 | −100 | 307.5 |
| symmetric | 0 | 0 | 0 | 0 | 0 |

FACT: Reversing the series does **not** swap legacy left/right errors
cleanly (`invariance_difference` median 200). Symmetric errors are
identically zero in both orientations.

INFERENCE: v0.2.1 asymmetry was **implementation directionality**:
wide `which.max` windows, `L = start[k]` instead of `start[k+1]`, and
index swapping. It is not an inherent property of the genome or of
Gaussian scores.

UNRESOLVED: None for noiseless coordinates.

**Failures.** None in the deterministic coordinate battery.

**Interpretation.** Mandatory reverse-invariance test **failed for
legacy** and **passed for the symmetric fix**. The fix is required
before a real-data pilot.

**Limitations.** Noiseless steps only; noisy/broad cases are later
reports.

**Decision: PASS** (after switching the default walker to `symmetric`)

**Next action.** Keep `legacy` available for audit; default is
`symmetric`.
