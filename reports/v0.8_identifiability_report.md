# v0.8 — Identifiability

## Objective

Test whether A–D collapse into arbitrary B/L splits.

## Methods

`identifiability_tests.tsv` / `component_leakage.tsv` (nrep=50):
broad-only 20 kb; local-only 400 bp.

## Results

FACT (mean counts):

| architecture | local calls \| broad-only | broad calls \| local-only |
| --- | ---: | ---: |
| A_additive | 0.00 | 0 |
| B_hierarchy | 0.02 | 0 |
| C_multires | **0.34** (P any local) | 0 |
| D_joint | 0.04 | 0 |
| flat controls | 0 (no scale types) | 0 |

FACT: A and B keep the TV/duration gap enough that broad-only
truth rarely invents locals. C’s fine residual level routinely
emits local structure (Gate G failure).

FACT: D rarely emits either component — under-calling, not
identifiable separation.

## Uncertainty

INFERENCE: A’s identifiability is “all residual after heavy TV,”
which also **absorbs** true nested locals (F3 p_both=0).

## Decision

C fails identifiability/leakage. D is non-operational. A/B
retain constraints; only B recovers any nested both-correct.
