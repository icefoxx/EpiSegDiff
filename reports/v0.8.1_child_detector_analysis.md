# v0.8.1 — Child detector analysis

## Methods

Same residual; compare fused (ref), fused with
`child_thr_mult=0.25`, and PELT child (nrep=50) on primary
L=1.5 and weak L=0.75 cells.

## Results

| config | primary p_both | false_child | leak (broad-only) |
| --- | ---: | ---: | ---: |
| ref (fused, thr×0.5) | 0.20 | 0.023 | 0.02 |
| child_thr025 | 0.20 | **0.12** | 0.04 |
| child_pelt | 0.00 | 0.00 | 0.00 |
| parent_median | 0.08 | 0.01 | 0.02 |
| parent_trim10 | 0.18 | 0.02 | 0.02 |
| reconcile | 0.06 | 0.00 | 0.00 |

FACT: lowering the MAD multiplier did **not** improve `p_both`
on the primary cell; it increased false children.

FACT: PELT-as-child detected no same-direction children here.

FACT: stagewise, `p_pass_threshold` equals final `p_both` for
ref — thresholding after fused is the operative bottleneck,
but simply lowering the threshold does not unlock true
isolations (fused often fails to carve a high-mean local
piece).

## Decision

No child-detector variant was selected for promotion.
