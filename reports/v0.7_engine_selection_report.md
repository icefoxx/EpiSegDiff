# v0.7 — Engine selection and Pareto

## Objective

Choose a production architecture from frozen metrics, not from
a single F1.

## Methods

Metrics (zeros included): narrow F1 (200, 500), broad F1 (10 kb,
50 kb), boundary error, merge rate, split rate, P(any false),
runtime class.

Automatic router `route_production_engine`: if
`MAD(diff(score)) / MAD(score) > 1.2` → standardized + fused
(`narrow`), else raw + PELT min3 (`broad`). Threshold frozen
before held-out (odd reps).

Weights were **not** used.

## Parameters

Roughness cut 1.2. Held-out seeds `85000+width+rep`.

## Results

FACT — Pareto-relevant points (mean F1):

| config | 200 | 500 | 2 kb | 10 kb | 50 kb | notes |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| raw+PELT min3 | 0 | 0 | 1 | 1 | 1 | v0.6 baseline |
| std+PELT min1 | 0.47 | 0.64 | 0.83 | 0.99 | 1.00 | fragments broad |
| raw+fused | 0.62 | 0.06 | 0.33 | 0.52 | 0.64 | wide error large |
| raw+HMM | 0.08 | 0.15 | 0.96 | 0.99 | 1.00 | |
| union fused∪PELT | 0.60 | 0.10 | 1 | 1 | 1 | no nested split |
| oracle | 0.62 | 0.65 | 1 | 1 | 1 | not deployable |

FACT: Candidate A (one engine everywhere) is dominated:
fused loses broad; PELT loses narrow.

FACT: Candidate B (union) equals the better single engine at
each isolated width and does not separate nested events.

FACT: Candidate C reference (std+PELT if width≤500 else
raw+PELT) has oracle gap 0.15 at 200 bp and ≈0 at ≥500 bp.
Width is **not** known at run time.

FACT (held-out router, no truth in the route):

- 200 / 500 / 2000 bp: **all** reps routed `narrow`
- 50 kb: **all** routed `broad` (F1=1)
- 10 kb: mixed 11 broad / 14 narrow per 25-rep split
- test F1: 200=0.40, 500=**0**, 2 kb=0.52 (vs PELT 1.00)

The roughness rule over-calls `narrow` on 2 kb blocks and
fails 500 bp on the test half.

## Uncertainty

INFERENCE: a width-oracle Candidate C is attractive on the
simulation grid and **is not** what the roughness router
delivers.

INFERENCE: automatic selection is **not** reliable enough for
a silent default.

UNRESOLVED: a better feature (local run-length, ACF at lag
equal to 3–5 bins) might route 2 kb to PELT; that was not
locked before seeing held-out truth, so it is not accepted
here.

## Failures

Selector overfits the roughness heuristic. Complexity of
HMM/HSMM/WBS adds no Pareto win over {PELT, fused, union}.

## Interpretation

Production recommendation (explicit, user-visible):

1. **Default / broad:** `raw_effect` + Gaussian PELT +
   `min_bins=3` (v0.6).
2. **Narrow-sensitive overlay:** `standardized` + PELT
   `min_width=1`, or fused lasso `min_width=1`, reported
   separately.
3. **Optional union** of (1) and (2) for isolated events.
4. **Do not** auto-switch on the current roughness cut.

Rejected for production default: WBS (this implementation),
binseg, global `standardized`, global fused, coarse-to-fine,
`signed_pval`, `hotelling`.

## Decision

Candidate C as a **documented pair of modes**, not an
automatic black box.
