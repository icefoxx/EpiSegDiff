# v0.5 — Independent dataset (GSE110378)

## Objective

Repeat the directional benchmark on Kdm6b-KO vs Control H3K27me3
(predeclared Dataset B).

## Methods

Four deposited H3K27me3 BigWigs, 200 bp mean, `log2+0.01`, filter
**quantile 0.75**, PELT 24, min_bins 3, contrast **KO − Control**.
Expected: GAIN of H3K27me3.

## Parameters

GSM2989282/83 Control; GSM2989284/85 KO; mm10.

## Results

FACT: ESD completed.

| | Dataset B ESD |
| --- | ---: |
| tested segments | 337,863 |
| GAIN | 4,411 |
| LOSS | 2,165 |
| min width | 600 |

GAIN > LOSS, matching the predeclared KDM6B biology.

FACT: hiddenDomains peaks were **not deposited**. Conventional

tractability floor of **15 bins (3 kb)** after a 317k-island run
proved infeasible.

Both methods are **GAIN-dominant**, matching KDM6B-KO biology.

## Uncertainty

337k ESD tested segments: quantile 0.75 on a broad mark. Call
*counts* are not comparable to GSE280947. The 3 kb island floor is
labeled POST HOC.

## Failures

for both ESD and the island comparator. The GSE280947 class-C
story is **not** claimed to reproduce (different conventional
