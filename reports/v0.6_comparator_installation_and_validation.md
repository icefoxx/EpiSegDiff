# v0.6 — Comparator installation and validation

## Objective

Record whether csaw, THOR, and the Layer-1 continuous comparators
can be run fairly.

## Methods

`requireNamespace` / `which` at selection time; Bioconductor
install of `csaw` 1.36.1; toy paired BAM via
`write_tiny_paired_sam` + `csaw::windowCounts`.

## Parameters

No real BAMs for GSE280947 or GSE110378 in the workspace.

## Results

| ESD PELT + limma | yes | USED | production |
| Fixed-peak limma | yes | USED (A IDR union) | v0.5 |

FACT: BigWig values were not sent to edgeR.

## Uncertainty

A toy BAM with 0 windows is a workflow smoke test, not a
scientific csaw benchmark.

## Failures

Real BAM-csaw and THOR cannot be run. Gate A therefore cannot
claim end-to-end external-method fairness on A/B.

## Interpretation

Layer-1 region-definition comparisons are valid. End-to-end
csaw/THOR ranking is **UNSUPPORTED**.

## Decision

Gate A: **CONDITIONAL** (continuous comparators OK; BAM methods
NOT_AVAILABLE).
