# v0.8.1 — Parent absorption

## Definition

`A = 1 - residual_local_effect / truth_L` on truth local bins
after parent residualization (`score - mean(parent)` by default).

## Results

FACT: thin-child absorption is ≈0.02–0.03 across B and L in the
20 kb / 400 bp primary geometry — consistent with
`A ≈ W_local/W_parent`.

FACT: absorption rises toward 1 as width ratio grows (e.g.
5000/10000 → A≈1; 2000/25000+ → A≈1 in the width grid).

FACT: changing parent to median/trim10 did not materially raise
`p_both` under the leakage guardrail (selection table).

## Interpretation

INFERENCE: for the v0.8 reference geometry, **redesigning the
parent estimator is not the first lever**. For fat nested
children, parent mean-subtraction is structurally absorptive
and needs a different orthogonalization.

## Decision

H2 is geometry-dependent. Parent sensitivity experiments did
not yield a promoted configuration.
