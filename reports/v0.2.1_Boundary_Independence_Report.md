# v0.2.1 — Boundary-inference independence (Task C)

**Objective.** Show that condition-specific boundaries \(B_C=(L_C,R_C)\)
and \(B_T=(L_T,R_T)\) can be inferred from local control/treatment
signal around a **differential** candidate, without MACS/SEACR.

**Hypothesis.** Differential discovery stays
\(\hat\beta(x)\rightarrow\) segmentation. Local `end_walk` on each
condition’s normalized mean recovers planted ends for *narrow* events;
broad events are harder because the local window contains long
high-signal stretches.

**Methods.** Planted GAIN intervals. Candidates are the known planted
windows (the discovery engine is peak-free; this test isolates the
local boundary step). `infer_local_condition_boundaries(..., method =
"end_walk")` walks each end to the local maximum of
\(|\Delta \mu_{\mathrm{condition}}|\`. No peak caller is invoked.

**Simulation design.** 288 runs:

- scales: narrow (8 bins × 50 bp) and broad (40 bins × 200 bp)
- effects 1.0 and 1.8; n_rep 3 and 5; depth 12 and 30
- normalization: TMM, background, library_size
- 6 Monte Carlo seeds per cell

Config/script: `scripts/run_boundary_independence_test.R`.
Table: `benchmark/simulation/boundary_validation.tsv`.

**Parameters.** Window = `max(8, 2 × width)` bins. `peak_caller =
"none"` on every row.

**Results.**

FACT: Every row records `peak_caller = none` and
`boundary_method = end_walk`.

FACT: Absolute end errors (bp):

| Scale | left median | left p90 | right median | right p90 |
|-------|------------:|---------:|-------------:|----------:|
| narrow | 350 | 350 | 0 | 400 |
| broad | 7800 | 7800 | 0 | 8000 |

FACT: Narrow events (400 bp planted width) have median left error of
350 bp (7 bins at 50 bp) and often exact right ends.

FACT: Broad events (8 kb planted width) have multi-kilobase left
errors. `end_walk` does not stably recover the left edge of a long
flat block.

INFERENCE: Topology **does not require** external peaks. Boundary
*accuracy* is scale-dependent and is not solved for broad domains by
this local method.

UNRESOLVED: Whether a local likelihood or cross-scale consensus would
cut broad-domain MAE substantially. Not claimed here.

**Uncertainty.** 144 runs per scale. Medians are identical across many
cells (errors snap to bin multiples).

**Failures.** Broad-domain left-end recovery fails the “quantitatively
recoverable” bar if that bar is sub-kb. Narrow-domain recovery is
usable.

**Interpretation.** Independence from peak callers: yes. Quantitative
recovery: yes for narrow, no for broad with `end_walk`.

**Limitations.** Only GAIN planted; expansion/shift boundary truth is
Task E. Window size is a free parameter.

**Decision: CONDITIONAL PASS (Gate C)**

Simulated narrow boundaries are recoverable without peaks. Broad-domain
errors are large and are reported by scale. Topology code paths never
call an external peak caller.

**Next action.** Treat broad-domain boundary MAE as an open accuracy
problem. It is a candidate justification for a later likelihood engine,
not a reason to call MACS.
