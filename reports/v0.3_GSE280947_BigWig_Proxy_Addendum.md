# v0.3 addendum — Level I from deposited bigWigs

**Objective.** Answer whether the available GEO files can be used
without SRA/BAM.

**Methods.** No BAM exists in this checkout. Eight deposited
spike-in+CPM bigWigs were imported with `rtracklayer`, averaged into
200 bp mm10 bins (chroms 1–19, X, Y), and analyzed as a **continuous
coverage proxy**.

This is **not** fragment counting and **not** the Negative-Binomial /
edgeR count model. Testing is limma on `log2(score + 0.01)` region
means. Contrast = JNKi − DMSO (GAIN = higher after inhibitor).

Signal mask: max JUN score ≥ 0.6 (IgG-in-peak mean ≈ 0.32; JUN-in-peak
≈ 0.95). Segmentation: Gaussian PELT, selected penalty 24, min width 3
bins (600 bp).

**Parameters.** `scripts/run_gse280947_bigwig_proxy.R`. Runtime 75 s
after import.

**Results.**

FACT: There are still **no BAMs**. BigWigs were usable.

FACT: QC on DMSO IDR bins:

| metric | value |
|--------|------:|
| DMSO JUN replicate *r* | 0.887 |
| JNKi JUN replicate *r* | 0.871 |
| mean DMSO JUN / IgG | 2.92 |
| mean JNKi JUN / IgG (same peaks) | 1.55 |
| mean DMSO JUN | 0.947 |
| mean JNKi JUN | 0.639 |

FACT: Level I (FDR ≤ 0.05): **630 LOSS**, **1 GAIN**. Median width
400 bp (p90 800 bp). Median LOSS log2FC = −1.16.

FACT: vs union of deposited IDR peaks: Class A (shared) **257**, Class
B (IDR only) **5144**, Class C (proxy-only) **374**.

INFERENCE: The proxy run is internally consistent with JNK-pathway
biology and with IDR peak shrinkage (4960 → 1632): JUN occupancy at
known sites falls after SP600125, and almost all DERs are LOSS. This
is **not** a substitute for a BAM/NB pilot.

UNRESOLVED: How many of these LOSS intervals would survive fragment
NB + TMM. Class B is large because IDR is *presence*, not
differential testing.

**Failures.** None in the proxy script after signal-masking. 50 bp
bins were not used (13.6 M bins at 200 bp already).

**Decision:** BigWigs **can** be used for a labeled coverage-proxy
Level I look. BAMs remain required for the official v0.3 count-assay
acceptance.
