# v0.2.2 — Boundary method comparison

**Objective.** Compare `legacy` end_walk, `symmetric` end_walk, and
local two-mean likelihood on the same series. No new model class.

**Methods.** 30 narrow (8×50 bp) and 30 broad (25×200 bp) mildly
noisy blocks. Candidate = truth ± 2 bins. Search radius 6. Reverse
pair for invariance. Table:
`benchmark/simulation/boundary_method_comparison.tsv`.
Stress grid (bin size, padding, radius, height, width):
`benchmark/simulation/boundary_parameter_stress.tsv` (3564 rows).

**Parameters.** Seed 20268 / 20267. Heights 1, 2, 4. Radii 3, 5, 10.

**Results.**

FACT: Median errors, method comparison (mild noise):

| method | scale | MAE_L | MAE_R | Hausdorff | inv. Δ |
|--------|-------|------:|------:|----------:|-------:|
| legacy | narrow | 50 | 0 | 50 | 100 |
| likelihood | narrow | 0 | 50 | 50 | 100 |
| **symmetric** | narrow | **0** | **0** | **0** | **0** |
| legacy | broad | 200 | 0 | 200 | 400 |
| likelihood | broad | 0 | 200 | 200 | 400 |
| **symmetric** | broad | **0** | **0** | **0** | **0** |

FACT: Runtime is negligible for all three (~0–1 ms per call).

FACT: In the *stress* grid, symmetric MAE is 0 on all narrow cells.
Broad cells with search radius ≪ domain width (e.g. r=3 on a 100-bin
block) miss the far end (median \|E_R\| several kb). That is search
support, not left/right code asymmetry (`A` is then large because the
right end was never in the window).

INFERENCE: Symmetric `end_walk` is the default. Likelihood is a
usable alternative but was slightly right-biased on this grid.
Legacy remains a negative control.

**Failures.** None that affect the default method on the comparison
design.

**Interpretation.** Narrow-domain error is explained and removed for
the symmetric walker when the candidate is within a few bins and `r`
covers the offset.

**Limitations.** Series-level, not full edgeR discovery.

**Decision: PASS** for method choice (`symmetric` default).

**Next action.** Document that `search_radius_bins` must cover candidate
error; do not use r=3 on 10–20 kb domains.
