# v0.4.2 — Final acceptance report

## Objective

Close the v0.4.1 `filter=none` blocker and decide
**PASS / CONDITIONAL PASS / FAIL** for unfiltered whole-genome
continuous segmentation under frozen statistical semantics.

## Methods

Phases 1–12 of
`EpiSegDiff_v0.4.2_Unfiltered_Segmentation_Scalability_Closure.md`.
No v0.5 work, no NB-FPOP, no BAM/BigWig equivalence claim, no
parameter retuning to make the run finish.

## Parameters

Frozen: continuous BigWig, mm10, 200 bp, `summary_fun=mean`,
`log2(score+0.01)`, limma, Gaussian PELT, `min_bins=3`,
`JNKi - DMSO`. Official none run uses `engine=pelt`, workers=1,
checkpoints on.

## Results — required questions

1. **What caused the v0.4.1 scalability failure?**
   FACT: unfiltered z-scores (`effect / max(|se|, 1e-6)`) give PELT
   a large candidate set (max \|R\| ≈ 15k on chr1 prefixes; worse
   on chrY). Combined with a monolithic 13.6M-row process, no
   checkpoints, and C++ that ignored `setTimeLimit`, the job looked
   hung after >30 min.

2. **Was the genome processed monolithically?**
   FACT: v0.4.1 already split CVRs by chromosome, but kept one
   process-wide track and no resume. v0.4.2 is explicitly
   chromosome-wise with checkpoint/release.

3. **Is segmentation now chromosome-independent?**
   Yes. PELT state is per chromosome. Tests reject mixed-chrom
   input to `segment_chromosome`.

4. **Are genuine contiguous blocks handled correctly?**
   Yes. Invalid, non-finite, and coordinate discontinuities define
   CVRs. A gap test emits no interval across the hole.

5. **Does computational chunking alter boundaries?**
   No arbitrary chunks were used. No reconciliation layer.

6. **Does new reproduce legacy on tractable domains?**
   Yes. Dispatcher = `segment_track` per chrom. chr1 prefix 20k:
   12 vs 12 segments, identical bounds. Absolute 0.6 full genome:
   2 GAIN / 688 LOSS / min 600.

7. **Before/after runtime and memory?**
   none: NOT_RUN → **2,245 s** complete. Peak RSS observed
   **7,406 MB** at the first chromosome, falling to 54 MB after
   chrY. 0.6 path still ~59 s.

8. **Is execution restartable?**
   Yes. chr19 checkpoint resumed in 0.026 s.

9. **Are incompatible checkpoints rejected?**
   Yes (`penalty` change → `Incompatible checkpoint`).

10. **Is parallelism deterministic?**
    Yes on the synthetic two-chrom test (`workers=1` vs `2`).
    Official none run used workers=1.

11. **Did the full `filter=none` run complete?**
    Yes. 21/21 chromosomes.

12. **Runtime and peak memory?**
    2,245 s; ~7.4 GB peak RSS during the live limma+track phase.

13. **GAIN/LOSS under `none`?**
    **4,866 GAIN / 4,608 LOSS** (9,474 DERs), 42,730 tested.

14. **Comparison with 2 GAIN / 688 LOSS?**
    Call counts differ by an order of magnitude. High-signal
    quartile of `none` remains LOSS-dominated (391 / 17).

15. **DER bp-Jaccard?**
    **0.016** vs the 0.6 reference.

16. **Direction/effect concordance?**
    Sign concordance 0.927 (all matched), 0.961 (strong), **1.0**
    on overlapping called regions. Effect Pearson 0.204 on all
    overlapping tested segments (granularity mismatch).

17. **How many none-only DERs are low signal?**
    9,365 none-only intervals; **97.3%** have max linear JUN < 0.6;
    median max linear 0.091. FDR≤0.05 mass sits in Q1–Q2.

18. **Are none-only low-signal regions replicate-consistent where
    assessable?**
    They have 2-vs-2 limma FDRs; Q1 median FDR is 0.059. That is
    statistical support under the working model, not proof of JUN
    occupancy. Not labeled false positives.

19. **Does removing the filter alter LOSS dominance?**
    **Yes, globally** (GAIN 4,866 vs LOSS 4,608). **No, in Q4**
    (17 GAIN / 391 LOSS).

20. **Do all prior critical regressions pass?**
    Yes (22 + 28 + 41 tests; 0.6 headline counts reproduced).

21. **Does any BigWig path call edgeR?**
    No.

22. **Final decision?**
    **PASS**.

23. **If PASS, can v0.4.x infrastructure work close and the
    project proceed?**
    Yes, under the documented assumptions. The next
    *scientific-development* version is a separate decision and
    was not started here.

## Uncertainty

INFERENCE: most `none` DERs are the previously masked low-signal
background stretched by `log2(x+0.01)` and tiny SEs. Jaccard vs
0.6 is therefore expected to be low.

chrY remains a long PELT job (33 min) and dominates wall time.

## Failures

Experimental FPOP was profiled and **rejected** for production
because its cost did not match PELT on real z-scores.

## Interpretation

Native BigWig continuous-assay infrastructure is
production-supported, **including tractable unfiltered
whole-genome execution**, via chromosome-wise restartable PELT.

PASS does **not** mean BigWig ≡ BAM, 200 bp is universal, 0.01 is
universal, or absolute 0.6 is universal. It does **not** mean the
4,866/4,608 none call set should replace 2/688 as the GSE280947
profile.
