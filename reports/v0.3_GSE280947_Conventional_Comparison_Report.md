# v0.3 — Conventional reference

**Objective.** Independent MACS2/IDR + fragment DE, then A/B/C vs
EpiSegDiff. Authors’ IDR is a **secondary presence** reference.

**Methods.** Downloaded deposited IDR beds. Did **not** run MACS2
(not installed) and did **not** recount fragments. Overlap is
reciprocal ≥ 0.2 on interval sets.

**Parameters.** IDR files
`GSM8607877_DMSO2_cJun_sorted.bed_idr.txt.gz`,
`GSM8607883_JNKI2_cJun_sorted.bed_idr.txt.gz`.

**Results.**

FACT: DMSO JUN IDR n=4,960 (median 643 bp). JNKi JUN IDR n=1,632
(median 601 bp). ~1,140 DMSO peaks overlap a JNKi peak; ~3,820
DMSO-only; ~488 JNKi-only.

FACT: This is **peak presence/absence**, not DiffBind/edgeR on
counts. It is not Class A/B/C.

INFERENCE: The deposited peak sets shrink after JNK inhibition,
which is compatible with H2 (occupancy changes) but is **not** an
EpiSegDiff result and must not be used to define EpiSegDiff
candidates.

UNRESOLVED: Which of the DMSO-only IDR peaks would be LOSS DERs
under fragment testing.

**Failures.** Own MACS2/IDR/edgeR conventional pipeline not run.

**Decision: PARTIAL** — deposited IDR archived; fragment-level
comparator blocked.

**Next action.** After BAM: MACS2 narrow vs condition-matched IgG,
default settings, then edgeR on the union, then A/B/C.
