# v0.8.1 — Same-direction failure localization

## Objective

Locate where same-direction nested children disappear in
`B_hierarchy` (Gate A).

## Methods

Instrumented `pathb_hierarchy_trace`: parent residual → raw
child segments (thr=0) → MAD-thresholded children → optional
reconciliation. Primary BxL grid nrep=100 (same-direction).

## Results

FACT (BxL same-direction, averaged over B):

| L | p_both | absorption | p_cand_raw | p_pass_thr | resid SNR |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.25 | 0.00 | 0.03 | 1.00 | 0.00 | 2.1 |
| 0.75 | 0.01 | 0.03 | 1.00 | 0.01 | 6.2 |
| 1.50 | 0.15 | 0.02 | 1.00 | 0.15 | 12.2 |
| 2.50 | 0.81 | 0.02 | 1.00 | 0.81 | 20.0 |
| 3.00 | 0.93 | 0.02 | 1.00 | 0.93 | 24.0 |

FACT: for thin children (400 bp / 20 kb), **absorption ≈ 0.02**.
Parent mean-subtraction does **not** remove the local increment.

FACT: `p_both ≈ p_pass_threshold`. Final failures coincide with
failing the child MAD threshold after fused segmentation of the
residual.

FACT: `p_candidate_exists≈1` at thr=0 is a **liberal** overlap
diagnostic (any residual piece overlapping truth). It does not
prove a high-mean isolated child segment exists.

FACT: correlations with `p_both`: residual SNR 0.74, L 0.72,
L/B 0.45, B 0.07, absorption −0.02.

FACT: when `W_local/W_parent` is large (e.g. 2–5 kb child in
10–100 kb parent), absorption → 1 — parent over-absorption
**does** dominate fat-child regimes.

## Hypotheses

| H | Verdict |
| --- | --- |
| H1 fundamental limit | UNRESOLVED as sole cause; SNR regime is sharp |
| H2 parent over-absorbs | **Rejected for thin children**; **supported for fat children** |
| H3 residual has child but detector/threshold fails | **Supported** as primary thin-child failure mode |
| H4 resolution | PARTIAL — 50 bp p_both 0.32 vs 200 bp 0.12 |
| H5 boundary proximity | PARTIAL — near-boundary not worse than center |
| H6 noise shifts \|L\| threshold | **Supported** |
| H7 reconciliation removes children | **Mostly rejected** for default (no reconcile); reconcile config does drop some |

## Decision

Gate A: **PASS** — loss localized.
