# v0.5 — Biological validation (Dataset A)

## Objective

Ask whether ESD-only (class C) intervals have independent support
relative to shared (A) and background.

## Methods

Predeclared TxDb mm10 annotation; nearest TSS; enrichGO BP;
JASPAR JUN + FOS::JUN via motifmatchr.

## Parameters

See predeclared plan.

## Results

### Annotation (FACT)

| class | promoter | intron | exon | intergenic |
| --- | ---: | ---: | ---: | ---: |
| A (shared) | 91 | 95 | 14 | 129 |
| C (ESD-only) | 234 | 49 | 16 | 62 |

Class C is **promoter-enriched** (234/361 ≈ 65%) versus A
(91/329 ≈ 28%).

### Motif (FACT)

Predeclared JASPAR2020 `MA0488.1` JUN and `MA0099.3` FOS::JUN,
`motifmatchr` p<1e-4, width-matched background (5× class C).

| class | n | motif+ | fraction |
| --- | ---: | ---: | ---: |
| A shared | 329 | 219 | **0.666** |
| B conventional-only | 1,361 | 526 | 0.386 |
| C ESD-only | 361 | 117 | 0.324 |
| background | 1,805 | 452 | 0.250 |

Class C vs background: OR **1.44**, Fisher p **0.0048**.

INFERENCE: ESD-only intervals are above genomic background but
**below** shared and conventional-only DERs. Motif support does not
argue that class C is better JUN sequence than peak-defined DERs.

### Pathways

FACT: enrichGO on class-C nearest Entrez IDs vs all ESD-called
nearest genes yields raw p < 0.05 for RNA-processing terms but
**BH q ≈ 0.96**. No significant pathway after correction.

### Orthogonal

IgG BigWigs exist but were not used as a formal enrichment test.
No matched RNA-seq in-package.

## Uncertainty

Nearest gene ≠ target. Promoter enrichment of C could be small
TSS-proximal JUN changes that IDR peaks also see at different
widths, or residual low-width calls.

## Failures

Motif scan not in the machine table.

## Interpretation

Independent support for class C is **modest motif enrichment vs
background** and **promoter shift**, without GO after BH, and with
**weaker** motif density than shared/peak DERs. Not an ESD win.

## Decision

Gate E: **PASS as a transparent finding** (support vs background;
no superiority vs peaks).

## Next action

Re-run motif with the corrected JASPAR query in a follow-up; do not
re-tune classes.
