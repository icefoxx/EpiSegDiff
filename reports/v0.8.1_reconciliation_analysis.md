# v0.8.1 — Reconciliation ablation

## Methods

Stages: raw residual segments → MAD threshold → optional rule
`|child| ≥ 0.5|parent|`.

## Results

FACT: default pipeline has **no** reconciliation beyond
thresholding; `p_retained|passed ≈ 1`.

FACT: enabling reconcile reduces primary `p_both` 0.20 → 0.06
and weak-child recovery to 0 — it removes true children.

## Decision

H7 rejected as the v0.8 default failure mode. Do not add this
reconcile rule.
