# v0.5 — Predeclared analysis plan

Frozen **before** final benchmarking interpretation. Later changes
must be labeled **post hoc**.

## 1. Datasets and contrasts

| ID | Accession | Contrast (numerator − denominator) | Expected direction |
| --- | --- | --- | --- |
| A | GSE280947 JUN | JNKi − DMSO | LOSS of JUN |
| B | GSE110378 H3K27me3 | KO − Control | GAIN of H3K27me3 |

Samples: the four JUN BigWigs (A); GSM2989282–85 (B).

## 2. EpiSegDiff primary config

**Dataset A (validated profile, not retuned):**

- continuous BigWig, 200 bp, `summary_fun=mean`
- `log2(score+0.01)`
- filter `absolute` **0.6**
- limma, Gaussian PELT, `min_bins=3`, FDR 0.05
- `filter=none` is **sensitivity only**

**Dataset B (scale unknown a priori):**

- same as A except filter = **`quantile` 0.75** of per-bin max
  (existing deterministic rule; not chosen to maximize DERs)

## 3. Comparator (Layer 1 — primary)

```
union of conventional peaks (A: IDR DMSO ∪ IDR JNKi;
 B: hiddenDomains Control ∪ KO)
→ mean of the same linear BigWig matrix over each peak
→ log2(x+0.01) → limma, same contrast, FDR 0.05
```

This isolates **region definition** from the observation model.

**Layer 2 (count/BAM):** NOT_AVAILABLE unless BAMs are present.
Normalized BigWig values are never sent to edgeR.

IDR/hiddenDomains peaks are **region definitions**, not differential
truth.

## 4. Genomic evaluation universe

Canonical autosomes + X + Y of the assay genome. Bins/peaks outside
that set are dropped.

## 5. Overlap definitions

Declared **before** seeing class counts:

- **1 bp overlap** (any)
- **reciprocal overlap ≥ 50%**
- **bp-level Jaccard**

**Class A (shared):** reciprocal overlap ≥ 50% **and** same sign.
**Class B:** conventional DER with no RO≥50% same-direction ESD DER.
**Class C:** ESD DER with no RO≥50% same-direction conventional DER.

Opposite-direction overlaps (any 1 bp, opposite sign) are counted
separately and not placed in A.

## 6. Motif source (JUN / Dataset A only)

Predeclared JASPAR2020 PWMs (not chosen after seeing class
enrichment):

- `MA0488.1` JUN
- `MA0099.3` FOS::JUN (AP-1)

A region is motif-positive if `motifmatchr` reports ≥1 hit at
`p < 1e-4` (package default-style cutoff, frozen here).

Background: width-matched, chromosome-matched random intervals in
the evaluable universe, excluding all DERs; 5× class C count.
BH adjustment across the two motifs × four region groups
(shared / B / C / background).

Dataset B is H3K27me3: motif support is **not applicable**
(NOT_AVAILABLE).

## 7. Annotation

One hierarchy from `TxDb.Mmusculus.UCSC.mm10.knownGene`:

1. promoter: TSS ± 2 kb
2. exon (non-promoter)
3. intron
4. intergenic
5. other

Seqnames mapped Ensembl ↔ UCSC (`1` ↔ `chr1`). Same rule for A, B,
and all classes.

## 8. Gene linkage

Nearest TSS (TxDb transcription start), signed distance. Nearest
gene ≠ regulatory target. Recorded as such.

## 9. Pathways

`clusterProfiler::enrichGO` Biological Process, universe = all
nearest genes of **tested** (not only called) regions of that
method, `pvalueCutoff=1`, BH on `p.adjust`. Compare class C vs
class B vs shared. No custom gene sets.

## 10. Negative controls

1. **All balanced 2+2 label partitions** other than the true and
   exact-reverse assignments (there are 4 remaining on 4 samples).
   Record GAIN/LOSS.
2. **Width-matched genomic background** (see motifs).
3. Dataset A `filter=none` is **not** a null; it is sensitivity.

Expect primary LOSS (A) / GAIN (B) counts to collapse toward
balance or toward zero DERs under scrambled labels.

## 11. Ablation

Same continuous matrix and limma:

1. full adaptive PELT (primary ESD)
2. **fixed bins:** each valid bin tested by limma; FDR≤0.05 bins
   are calls (no PELT). Adjacent same-sign calls are **not** merged
   in the primary ablation table; a merged version is secondary.
3. **fixed peaks:** Layer 1 conventional

## 12. Synthetic truth

Toy BigWigs / matrices with planted:

- narrow GAIN / LOSS (6 bins)
- broad GAIN / LOSS (20 bins)
- nearby same-direction (gap 4 bins)
- nearby opposite-direction (gap 4 bins)
- event that **crosses** a planted conventional peak boundary

Metrics: bp precision/recall, detection (any 1 bp of truth),
direction accuracy, boundary L1 error.

## 13. Primary metrics

See taskbook §8. Fragmentation (predeclared):

```
frag_index = (# conventional peaks with 1 bp overlap to an ESD DER)
             / (# ESD DERs)
peaks_per_ESD = conventional peaks overlapping each ESD DER
```

## 14. Robustness

Reuse v0.4.1 12-cell grid (already run). Ask only: does LOSS
dominance on Dataset A reverse? `filter=none` is secondary
sensitivity (v0.4.2 numbers).

## 15. Multiple testing

limma BH within each method’s tested-region universe. Motif BH as
above. No cross-method BH (different hypotheses).

## 16. Track-locus rule

Example loci = the 3 widest class-C DERs and 3 widest class-B DERs
on Dataset A, listed by coordinates — not chosen by eye.
