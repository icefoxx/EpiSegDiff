# v0.8 — Candidate model specifications (Stage 1)

## Objective

Formalize Path B candidates **A–D** before major coding. Flat
engines remain controls. No production freeze yet.

## Shared observation model

Continuous BigWig path unchanged: length-weighted bin means →
differential score \(D(x)\) (default `raw_effect`;
`standardized` as a control score).

Inference (limma / descriptive) is **downstream** of discovery
and is not claimed as region-level FDR unless calibrated.

Frozen numerical effects for primary cells:

```text
weak Δ = 0.5
moderate Δ = 1.5
strong Δ = 3.0
noise low/moderate/high = 0.1 / 0.2 / 0.4
```

## Candidate A — Additive broad + local (sequential)

### Objective

\[
\min_{B,L}\ \|D-B-L\|_2^2 + \lambda_B\,\mathrm{TV}(B) + \lambda_L\,\mathrm{TV}(L)
\]

solved **sequentially** (prototype):

1. \(\hat B = \mathrm{TV}(D;\lambda_B)\) with large \(\lambda_B\)
   (broad/smooth);
2. \(\hat L = D-\hat B\);
3. segment \(\hat B\) with PELT `min_width = w_B`;
4. segment \(\hat L\) with fused `min_width = 1`.

### Identifiability

Broad = low total variation (large \(\lambda_B\)). Local =
residual after broad. Without the TV gap, \(B\) and \(L\) are
not unique.

### Parameters

`lambda_B_mult` (× MAD(diff(D))), `w_B` (bins), call threshold
on segment means (frozen MAD rule).

### Expected failures

Edge ringing → false local near broad boundaries (F7).
Broad-only truth → residual noise called as local (F8 / Gate G).

### Complexity

\(O(n\cdot I_{\mathrm{TV}} + n\log n)\) per series.

## Candidate B — Hierarchical segmentation tree

### Objective

1. Parents: PELT on \(D\) with `min_width = w_B`.
2. Children: within each parent with \(|\bar D|>t\), residual
   \(R = D-\bar D_{\mathrm{parent}}\) on that interval; fused on
   \(R\).
3. Emit `parent_id` / `level`.

### Identifiability

Scale = tree depth + parent duration constraint. Local events
exist only as children of an accepted parent (or as orphans if
`allow_orphan_local=TRUE` for isolated narrow F1).

### Parameters

`w_B`, parent threshold, child fused λ, max depth = 2 in the
minimal prototype.

### Expected failures

Deep trees if depth uncapped. Parent miss → child miss. False
children from residual noise (F8).

### Complexity

One PELT + one fused per parent.

## Candidate C — Explicit multiresolution

### Objective

\[
D = D_{\mathrm{coarse}} + D_{\mathrm{medium}} + D_{\mathrm{fine}}
\]

Prototype:

1. Coarse: mean-pool factor \(k_c=5\), PELT → broad;
2. Medium: factor \(k_m=2\) residual vs coarse → intermediate;
3. Fine: residual at native resolution → fused local;
4. Assign `component_type` by generation scale.

### Identifiability

Scale index of the decomposition level (not a hard kb cutoff).

### Parameters

`k_c`, `k_m`, PELT/fused penalties per level.

### Expected failures

Unstable under resolution change (Gate: scale stability).
Leakage across adjacent levels.

## Candidate D — Joint multiscale penalized likelihood

### Objective (Gaussian prototype)

\[
\mathcal{J}(B,L)=\|D-B-L\|_2^2+\lambda_B\mathrm{TV}(B)+\lambda_L\mathrm{TV}(L)
\]

Alternating minimization (80 iters):

```text
B ← TV(D − L; λ_B)
L ← TV(D − B; λ_L)   with λ_L ≪ λ_B
```

Then segment \(B\) (PELT, long) and \(L\) (fused, short).

### Identifiability

Explicit dual TV penalties with \(\lambda_B/\lambda_L \gg 1\).

### Expected failures

If ratio too small, non-identifiable swap. Soft separation may
under-call nested locals.

### Complexity

\(O(I_{\mathrm{alt}}\cdot I_{\mathrm{TV}}\cdot n)\).

## Inference compatibility (all candidates)

Discovery emits candidates with `component_type ∈ {broad,local}`
and optional hierarchy. Testing may use same-data limma on
region means (**descriptive support**, not claimed FDR).

Declared provisional inferential target for reporting:

```text
family-wise P(any false region) under MAD-threshold discovery
+ component leakage rates
```

Region-level FDR is **not** the production claim until Gate H
passes with an explicit family.

## Uncertainty

SPECULATION: sequential A is simplest to debug but most prone
to F7/F8 leakage. Joint D may reduce leakage if the λ ratio is
identifiable. Hierarchy B matches nested truth syntax most
directly.

## Decision

Proceed to Stage 2 minimal prototypes for A–D with identical
falsifiers F1–F9 (F10 real-data later).
