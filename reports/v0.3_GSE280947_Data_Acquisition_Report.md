# v0.3 — GSE280947 data acquisition (Gate 0)

**Objective.** Retrieve and verify metadata and raw paired-end data
for the four JUN and four IgG samples. Stop if identities or layout
do not match the specification.

**Methods.** GEO series/sample text (`acc.cgi?form=text`). ENA
`filereport` for PRJNA1181529 (run accessions, layout, read counts,
FASTQ MD5). HTTPS download of deposited MACS2/IDR beds. No SRA
prefetch (toolkit not installed).

**Parameters.** Accessions as specified in the v0.3 plan.

**Results.**

FACT: GSE280947 is public (2026-01-20), mouse Min6, 48 h DMSO vs
20 µM SP600125, CUTANA CUT&RUN, 2×150 NovaSeq, ~30M PE reads,
assembly **mm10 / GRCm38**, BioProject **PRJNA1181529**.

FACT: Sample identities match the spec.

FACT: All eight JUN+IgG runs are **PAIRED**. MD5s for both mates are
in `data/GSE280947/metadata/fastq_checksums.tsv`. FASTQ files
themselves are **not** on disk.

FACT: Deposited IDR beds downloaded:

- DMSO JUN IDR: 4,960 intervals (median width 643 bp)
- JNKi JUN IDR: 1,632 intervals (median width 601 bp)

FACT: This machine has no `prefetch`/`fasterq-dump`, no `bowtie2`,
no `samtools`, no `macs2`, and ~41 GB free. Eight PE FASTQs plus
BAMs plus an mm10 index will not fit and cannot be aligned here.

INFERENCE: Metadata Gate 0 **passes**. Raw-data/alignment Gate 0
**fails** for operational reasons, not because GEO disagrees with
the plan.

UNRESOLVED: On-disk FASTQ integrity (checksums cannot be verified
until files are downloaded).

**Failures.** Raw FASTQ/BAM absent. EpiSegDiff was **not** pointed
at deposited spike-in+CPM bigWigs.

**Decision: STOP after Gate 0 for the genome-wide run.** Metadata
is locked. Processing notes:
`data/GSE280947/metadata/processing_notes.md`.

**Next action.** On a workstation with SRA toolkit, Bowtie2, samtools,
mm10+E.coli indexes, and ≥150 GB free, download the eight SRR FASTQs,
verify MD5s, align, then `scripts/run_gse280947_pilot.R`.
