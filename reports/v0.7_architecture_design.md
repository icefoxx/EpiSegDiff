# v0.7 — Architecture design

## Objective

Separate observation, score, segmentation, refinement, and
inference so engines can be compared without hard-coding a winner.

## Methods

New interfaces: `compute_diff_score`, `segment_signal`,
`refine_boundaries`, `infer_regions`, `run_multiscale`,
`run_crossfit`, `union_resolve_calls`, `hierarchical_refine`.

## Parameters

v0.6 `200 bp + PELT + min_bins=3 + se-floor z` is **baseline only**.

## Results

FACT, implemented scores: `raw_effect`, `log_effect`,
`moderated_t`, `standardized` (Δ / sqrt(s²_pooled + MAD(Δ)²)),
`signed_pval` (exploratory), `hotelling` (signed √T²).

FACT, implemented engines: `pelt`, `fpop`, `binseg`, `wbs`,
`fused_lasso` (1-D TV denoise + jump cps), `hmm` (3-state
Viterbi), `hsmm` (HMM + duration merge).

FACT, inference: same-data, pooled-signal geometry, sample split
(1+1 descriptive |Δ|≥0.5), cross-fit union.

FACT, multi-scale: single, coarse-to-fine (×5), candidate union
with greedy |effect| conflict resolution.

## Uncertainty

INFERENCE: fused lasso / WBS with `min_width=1` is how narrow
events can exist without globally dropping PELT’s floor.

## Failures

None at interface construction.

## Interpretation

Gate A starts here. Rejected engines will stay in tables.

## Decision

Proceed to factorial benchmark with **nrep=50** on the primary
width set {200, 500, 2000, 10000, 50000}.

## Next action

Do not pick a production engine before the tables exist.
